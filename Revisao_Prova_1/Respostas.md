1 - Dado Pessoal: Os dados pessoais, são os dados pertencentes à um indivíduo como nome, telefone, endereço e etc. Dado sensível: São dados que são sensíveis e protegidos pela LGPD como por exemplo, cpf, idade, nome completo, biometria e etc. Dado anonimizado: São dados que são ocultos/protegidos deixando anônimo para proteger o indivíduo proprietário daqueles dados, isso é muito utilizado em sistemas médicos, onde é necessário anonimizar os dados de um beneficiário para que o mesmo não seja exposto de alguma forma.
